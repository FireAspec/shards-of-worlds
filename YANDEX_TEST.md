# Первая тестовая загрузка в Яндекс.Игры

## 1. Подготовка Godot

Проект рассчитан на Godot 4.x и уже содержит Web export preset.

Если пункт Web недоступен в окне экспорта, установите Export Templates для используемой версии Godot.

## 2. Web-экспорт

1. Откройте проект в Godot.
2. Выберите **Project → Export**.
3. Выберите preset **Web**.
4. Нажмите **Export Project**.
5. Путь по умолчанию: `build/web/index.html`.

Для загрузки в Яндекс.Игры упакуйте **содержимое** папки `build/web` в ZIP, чтобы `index.html` лежал в корне архива.

## 3. SDK

Игра сама динамически подключает официальный SDK по пути `/sdk.js`.

На обычном локальном запуске вне Яндекс.Игр SDK может быть недоступен — это нормально: сама игра продолжает работать, а платформенные функции остаются неактивными.

После инициализации SDK игра вызывает `LoadingAPI.ready()`.

Звук автоматически отключается:
- при уходе со вкладки;
- на время rewarded-рекламы.

## 4. Таблица лидеров

В консоли Яндекс.Игр создайте leaderboard с техническим именем:

`shards_total`

В рейтинг отправляется общее число собранных осколков.

Для записи результата игроку требуется авторизация в Яндексе. В самой игре вход вызывается только отдельной кнопкой **ВОЙТИ**, после объяснения преимуществ авторизации.

## 5. Облачное сохранение

Локальное сохранение остаётся в `user://shards_save.json`.

При доступном Player API игра дополнительно синхронизирует:
- текущие осколки;
- суммарно собранные осколки;
- открытую главу;
- уровни всех улучшений;
- время последнего сохранения.

При загрузке выбирается более свежее состояние.

## 6. Rewarded-реклама

В Web-версии появляется кнопка **×2 ЗА РЕКЛАМУ**.

После успешного просмотра игрок получает режим **Резонанс ×2** на 60 секунд.

## 7. Что проверить в debug panel Яндекс.Игр

- SDK loader: `IT`.
- Game Ready становится зелёным после появления игрового интерфейса.
- При смене вкладки звук прекращается.
- Во время rewarded-рекламы звук прекращается.
- После авторизации работает leaderboard `shards_total`.
- После перезапуска сохраняется прогресс.

## 8. Перед отправкой на модерацию

Первая задача этой сборки — проверить сам процесс загрузки и работу SDK. После этого можно отдельно заниматься балансом, локализацией, рекламными паузами и финальной визуальной полировкой.
