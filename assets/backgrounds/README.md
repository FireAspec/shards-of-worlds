# Полноэкранные фоны

Игра использует 13 утверждённых полноэкранных фонов:

`01_horikita.webp`, `02_ichinose.webp`, `03_kaguya.webp`, `04_asuna.webp`, `05_elizabeth.webp`, `06_yumeko.webp`, `07_emilia.webp`, `08_frieren.webp`, `09_yor.webp`, `10_ruby.webp`, `11_ai.webp`, `12_roxy.webp`, `13_ayanokoji.webp`.

Текущие версии подготовлены в размере 2048×1365.

## Улучшение качества

Имена файлов закреплены за персонажами. Можно в любой момент апскейлить или вручную улучшить изображение и заменить файл **с тем же именем**. Никаких изменений в GDScript для этого не требуется.

Например, улучшенный фон Фрирен должен остаться `08_frieren.webp`.

Желательно сохранять соотношение сторон текущего игрового окна. Если фон имеет более высокое разрешение, Godot масштабирует его под окно без изменения игровой логики.
