# Полноэкранные фоны

Игра ожидает 13 утверждённых полноэкранных фонов в этой папке:

`01_horikita.webp`, `02_ichinose.webp`, `03_kaguya.webp`, `04_asuna.webp`, `05_elizabeth.webp`, `06_yumeko.webp`, `07_emilia.webp`, `08_frieren.webp`, `09_yor.webp`, `10_ruby.webp`, `11_ai.webp`, `12_roxy.webp`, `13_ayanokoji.webp`.

Все изображения приведены к 2048×1365 без растяжения персонажей: исходник вписывается целиком, а свободное пространство заполняется затемнённой/размытой версией того же изображения.

Если полноэкранный фон отсутствует, игра безопасно откатывается к портрету персонажа из `assets/gallery/`.
