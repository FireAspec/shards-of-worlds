# Осколки миров

Сюжетный кликер на Godot 4.x с коллекцией персонажей и полноэкранными темами.

## Текущая версия

- утверждённый интерфейс в стиле `SHARDS OF WORLDS`;
- 13 персонажей, которые открываются последовательно по прогрессу;
- будущие персонажи не показываются заранее;
- любого уже открытого персонажа можно выбрать активным;
- активный персонаж меняет полноэкранный фон, портрет, цитату и игровой бонус;
- 12 ступеней ручной и автоматической прокачки;
- критические клики, редкие осколки и режим «Резонанс ×2»;
- автоматический и офлайн-доход;
- локальное сохранение прогресса и выбранного персонажа;
- отдельные полноэкранные фоны 2048×1365 для всех 13 персонажей;
- отдельные портреты для карточек коллекции;
- финальная 13-я награда сохраняет «ТЫ ДОСТИГ СОВЕРШЕНСТВА» и Аянокоджи с CHIPS;
- подготовлен Web export preset для дальнейшей загрузки в Яндекс.Игры.

## Запуск

1. Открыть папку проекта в Godot 4.3 или новее.
2. Открыть `project.godot`.
3. Запустить F6/F5.

## Персонажи

Полная таблица персонажей, бонусов и поведения выбора находится в [CHARACTERS.md](CHARACTERS.md).

## Замена / улучшение графики

Полноэкранные изображения лежат в `assets/backgrounds/`, портреты — в `assets/gallery/`.

Имена файлов считаются стабильными. Если фон будет улучшен или апскейлен, достаточно заменить соответствующий файл, сохранив его имя, например:

`08_frieren.webp` → улучшенный `08_frieren.webp`.

Код, прогресс и бонусы персонажа менять не требуется.

## Яндекс.Игры

Файлы подготовки под Web и ранняя SDK-заготовка сохранены в репозитории. После окончательной полировки локальной версии платформенная интеграция будет снова проверена целиком перед первой загрузкой.
