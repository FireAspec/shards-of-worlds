# Осколки миров

Сюжетный кликер на Godot 4.x.

## Текущая версия

- ручной клик с анимацией и критическими импульсами;
- 12 типов улучшений и автоматизации;
- экономика от единиц до триллионов и выше;
- 13 этапов прогресса и коллекционная галерея;
- автоматический доход;
- офлайн-доход максимум за 8 часов;
- локальное сохранение в `user://shards_save.json`;
- встроенные звуковые эффекты без внешних аудиофайлов;\n- структура для CG-иллюстраций и Web-публикации.

## Запуск

1. Открыть папку проекта в Godot 4.x.
2. Запустить проект клавишей F6/F5.

## В разработке

- полноценный визуальный стиль;
- CG-иллюстрации для сюжетных этапов;
- экран галереи;
- дополнительные сюжетные сцены;
- эффекты и анимации;
- Web-экспорт;
- интеграция с Yandex Games SDK.
